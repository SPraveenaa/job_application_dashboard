# Job Tracker App

A simple Job Tracker application built with React, TypeScript, and Tailwind CSS.

---

## Features / Funktionen
- Add, edit, and delete jobs / Jobs hinzufügen, bearbeiten und löschen
- Filter jobs by status: applied, interview, offer, rejected / Jobs nach Status filtern: applied, interview, offer, rejected
- Search jobs by title or company / Jobs nach Titel oder Firma durchsuchen
- Responsive design / Responsives Design

---

## Installation / Installation
```bash
git clone <repository-url>
cd job-tracker-app
npm install
npm start
